# NEON RECLAIMER

敵を倒してコインを集め、装備を組み合わせて先の区画へ進む3Dアクションです。倒されてもコア強化が残り、次の挑戦につながります。

[ブラウザで遊ぶ](https://blueberry1001.github.io/neon-reclaimer-play/?v=barrier-balance-2)

## 操作

| 操作 | PCの初期設定 |
| --- | --- |
| 移動 / 視点 | WASD / マウス |
| 攻撃 / 溜め攻撃 | 左クリック / 長押しして離す |
| 回避 | Shift / 右クリック |
| ジャンプ | Space |
| 必殺技 | Q（区画10で解放） |
| 装備強化 / 一時停止 | E / Esc |
| カメラ距離 | ホイール |

ジャンプして十分な高さで攻撃すると落下攻撃。銃・ドローン・購入したパルスは自動で攻撃します。設定からキー割り当て・感度・音量を変えられます。

スマホでは左のスティックで移動し、右側をなぞって視点を動かします。攻撃・回避・ジャンプ・必殺技・メニューは画面のボタンで操作できます。タイトルでPC操作とタッチ操作を切り替えられます。「全画面」は対応ブラウザで利用できます。

## 装備と再挑戦

装備Lv3で武器の進化先を選び、Lv8から専用強化を購入できます。近接武器・銃・ドローンの命中効果、会心、防御、回復などを組み合わせて戦います。区画10からは、大ダメージの「星核崩壊」、高速攻撃の「限界駆動」、攻撃を当てるほど強くなる「戦鬼解放」を選べます。

条件を満たして敵を全滅させると、カウントダウン後に次の区画へ進みます。15種類の地形を巡り、3区画ごとにボスが出現します。境界機リミナルは、安全地帯への移動・危険地帯からの退避・衝撃波を跳び越す動きを使い分けて戦うボスです。

倒されると装備はリセットされ、コインの20%とコア強化を引き継ぎます。使ったコインも獲得コアの計算に含まれます。コア強化は39項目。ツリーはドラッグで移動、ホイールで拡大縮小できます。

シールドの上限は最大HPの3倍です。割れた一撃のダメージはHPに通りません。破壊後1秒はシールドを得られないので、回避して立て直しましょう。

## 保存

進行はブラウザに保存されます。「つづきから」で再開し、「はじめから」は確認後に進行を初期化します。サイトデータを削除すると保存も消えます。既存のセーブは引き継げます。
