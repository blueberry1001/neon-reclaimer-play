# NEON RECLAIMER

敵を倒して装備を選び、どこまで進めるかに挑む3Dアクションです。

[ブラウザで遊ぶ](https://blueberry1001.github.io/neon-reclaimer-play/?v=weapons-builds-1)

## 操作

WASDで移動、マウスでカメラ回転、左クリック・長押しで3連撃。Shiftで回避、Spaceでジャンプ、ホイールでカメラ距離、Eで装備強化、Escで一時停止します。回避は2回分あり、最後に使ってから2.5秒で補充。ジャンプ・回避で攻撃を中断できます。銃・ドローン・パルスは自動発動です。

## 挑戦と成長

撃破条件を満たし、残った敵をすべて倒すと、3秒のカウントダウン後に次の区画へ移動します。カウントダウン中も移動できます。移動先で装備画面が開き、「戦闘を始める」で再開します。3種の地形を巡り、3区画ごとにボスが出現。先へ進むほど敵の強さと報酬が上がります。手動で周回を確定する操作はなく、倒されるまで進みます。

死亡すると、コインの20%、累積コア、恒久研究を残して区画1から再挑戦。銃を含む装備レベルと武器分岐はリセットされます。稼いだコインは使った分も死亡時のコア獲得に加算され、端数も引き継ぎます。

死亡演出が終わると恒久研究が開きます。広いツリーをドラッグ・ホイールで移動できます。平面に枝分かれする22ノードがあり、前提の研究から次の能力へ進めます。3段目の爆風、ジャンプ着地の衝撃、移動による範囲攻撃など、得意な行動を選べます。回避後の強化射撃、標準ライフルの連鎖電撃、空中連射、余剰回復のシールド化、追従衛星、コイン回収による衝撃などを組み合わせられます。研究に使っても累計コアの自動ボーナスは減りません。

## 武器の選択

剣Lv3で重い一撃の大剣か、細く長い射程の槍へ分岐できます。銃Lv3では、敵を貫くビームか近距離の散弾を選べます。Lv3への強化時に必ずどちらかを選びます。選択後は分岐画面を表示しません。選択後はその挑戦中には戻せません。

ビームは1.4秒間照射し、当たり続けた敵へ継続ダメージを与えます。槍は突き、重刃は両手の重い斬撃です。

ライフルは肩の横に浮かび、レベルで威力と発射間隔を強化します。近接武器の3段目は長射程・高倍率の斬撃です。

## 挑戦中のビルド

コインでHP・防御・移動速度も強化できます。恒久研究はHP倍率・割合軽減などで通常強化を補強します。ドローンは命中で敵を減速させ、Lv3で追跡型（敵へのダメージを15%増加）か爆撃型（周囲に追加ダメージ）を選びます。これらの通常強化と武器・機体分岐は死亡時にリセットされます。

## 保存

タイトルの「はじめから」は確認後にコイン・コア・研究・記録を初期化します。「つづきから」で保存済みの進行を再開できます。進行はブラウザに保存します。サイトデータを消すと保存も消えます。旧セーブの進行と研究は引き継ぎます。旧版で所持していたライフルは進行中の挑戦ではLv1として残り、次の死亡時にリセットされます。
