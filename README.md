# NEON RECLAIMER

敵を倒して装備を選び、どこまで進めるかに挑む3Dアクションです。

[現在の公開版で遊ぶ](https://blueberry1001.github.io/neon-reclaimer-play/?v=expedition-oct4-1)

## 操作

タイトルでPC操作とタッチ操作を切り替えられます。スマホはタッチ操作が初期設定です。左下のスティックで移動し、右側をなぞって視点を動かします。攻撃・回避・ジャンプ・強化・一時停止は画面のボタンで操作できます。PC操作ではタッチボタンを表示しません。

| PCの初期設定 | 操作 |
|---|---|
| WASD | 移動 |
| マウス移動 | カメラ回転 |
| 左クリック | 通常攻撃。続けて押すと3連撃 |
| 左クリック長押し→離す | 最初の1段の後に溜め、離すと強攻撃 |
| Space | ジャンプ。地上攻撃の中断にも使用 |
| Shift／右クリック | 回避。攻撃中も使用可能 |
| ホイール | カメラ距離 |
| E | 装備強化・ステータス |
| Q | 必殺技 |
| Tab | 戦闘データのページ切り替え・折りたたみ |
| Esc | 一時停止 |

ジャンプで十分な高さに達してから攻撃すると、武器ごとの構えを挟んで落下攻撃を出します。落差が大きいほど威力が上がります。落下攻撃を強化すると、着地後の硬直も短くなります。溜め中にジャンプした場合は、攻撃をいったん離してから押し直してください。銃・ドローン・購入後のパルスは自動で発動します。

回避は初期2回分あり、最後に使ってから初期2.5秒で補充されます。コインで最大8回まで増やせるほか、クールタイムや距離も強化できます。

タイトル・一時停止の「設定」で感度、音量、キー割り当てを変更できます。「全画面」は対応ブラウザの表示領域を広げます。非対応のiPhoneではホーム画面から開く方法を案内します。タッチ操作は横向きを推奨しますが、縦向きのメニューもスクロールできます。

## 挑戦とコア強化

区画の撃破条件を満たして敵を全滅させると、3秒後に次の区画へ移動します。カウントダウン中も移動・攻撃でき、演出も動き続けます。移動先で装備画面が開き、「戦闘を始める」で再開します。

17種の地形を巡り、通常の戦闘区画では3区画ごとに7種のボスが順に登場します。先へ進むほど敵の攻撃と報酬が増えます。遠距離攻撃、跳躍、正面防御、仲間の支援を使う敵や、安全な位置が切り替わるボスがいます。

「風走回廊」は広い夜の戦闘エリア。「断層連絡橋」は足場を渡って奥のゲートに着くとクリアです。敵は出現し続けるので、回避距離や回数を強化してから進めます。落下するとHPを少し失って中継地点へ戻ります。

装備の想定火力が区画の基準を大きく超えていると、強化画面に先の区画へ進むボタンが現れます。確認後に移動し、装備・HP・所持コインはそのまま引き継ぎます。飛ばした区画の報酬は得られません。

倒されると、コインの20%、累積コア、コア強化を残して再挑戦できます。装備レベル・武器分岐・専用強化は失います。稼いだコインは使った分もコア獲得へ加算され、端数は次へ引き継ぎます。

一時停止の「挑戦を終了」でも、確認後に同じ精算をしてタイトルへ戻れます。この場合は「コア強化へ」から強化と再挑戦へ進めます。「タイトルに戻る」は進行を残して中断します。「はじめから」は確認後にコアを含む全進行を初期化します。

コア強化は39項目のツリーです。ドラッグで移動し、ホイールまたは＋／−で拡縮できます。全攻撃・HPなどの基礎能力に加え、回避直後、空中、シールドがある間、コインをためているときなど、条件に応じた強化を選べます。コアを使っても累計コアによる収入ボーナスは減りません。

死亡後は自動でコア画面が開きます。買える強化が残っているときだけ、再挑戦前に確認が表示されます。挑戦中は装備画面の「ステータス」で取得済みの効果を確認できます。

## 武器とビルド

近接・銃・ドローンはLv3で形態を選びます。標準型の継続も選択肢に含み、その挑戦中の選び直しはできません。双短剣・回転斧・双長剣はコア強化で解放します。

| 近接武器 | 特徴 |
|---|---|
| 片手剣 | 扱いやすい連撃。専用強化でガードとカウンター |
| 大剣 | 重い斬撃と強力な溜め・落下攻撃 |
| 槍 | 遠くへ届く突き。専用強化でさらに射程を延長 |
| 双短剣 | 短い間合いの高速連撃と会心・移動の連携 |
| 回転斧 | 長押しで回り続け、命中時の吸収や防御強化と組み合わせる |
| 双長剣 | 広い交差斬り。専用強化で溜め・落下の強化分を通常攻撃へ転換 |
| 共鳴鎌 | 初動は控えめ。直接攻撃を当て続けるほど、その挑戦中の火力が成長 |

共鳴鎌はコア強化なしでLv3の選択肢に現れます。共鳴は区画をまたいで蓄積し、死亡・挑戦終了でリセットされます。銃やドローンの命中では増えません。

銃は一発が重いライフル、継続照射するビーム、近距離の散弾から選びます。ライフルはレベルや専用強化で自動射撃の威力が伸びます。ドローンは敵を減速させ、追跡型のマークや爆撃型の範囲攻撃へ分岐できます。パルスはコインで取得し、確率で敵を短時間止めます。

Lv8から各装備の「専用強化」を購入できます。威力・速度に加え、回復、シールド、会心、装備銃による追撃などを組み合わせます。双長剣の「連舞転換」は、溜め・落下の購入強化分を通常攻撃にも20%／Lv、最大100%適用します。

レベル上限は近接40、銃30、ドローン30、パルス25。基礎攻撃力・HP・防御・移動速度・会心率・会心ダメージもコインで強化できます。

区画10で必殺技が解放されます。与えたダメージでゲージをため、周囲への大ダメージ、短時間の高速化、命中でさらに強くなる自己強化から選べます。

## 戦闘中の表示

右側の戦闘データでは、区画の総ダメージ、直近10秒のDPS、経過時間、獲得コイン、HP被ダメージなどを確認できます。命中・回復・会心の集計や、攻撃手段別の内訳もあります。総ダメージは敵の残りHPを超えた分を含み、有効ダメージは実際に減らしたHPです。メニュー中は集計時間を止めます。

会心は黄色のダメージ文字で表示します。ボスHPは上部中央の赤いゲージ、シールドはプレイヤーHPの下に表示します。シールドは最大HPの3倍まで蓄積し、壊れた一撃の余りはHPへ通しません。壊れてから1秒間は新しいシールドを作れません。

刀身の軌跡、溜め中の発光、落下攻撃は武器ごとの色と形で表示します。共鳴鎌は赤と黒、双長剣は青い交差線、槍は若草色の細い斬線が目印です。

「図鑑・ヘルプ」で画像付きの説明を読めます。短いチュートリアルは「はじめから」を選んだときに流れます。
