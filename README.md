# NEON RECLAIMER

敵を倒して装備を選び、どこまで進めるかに挑む3Dアクションです。

[ブラウザで遊ぶ](https://blueberry1001.github.io/neon-reclaimer-play/?v=mobile-builds-1)

## 操作

タイトルで「PC操作」「タッチ操作」を切り替えられます。スマホはタッチ操作が初期設定。左下スティックで移動、右側をなぞって視点移動、右下の攻撃（長押し→離すと溜め）・回避・ジャンプを使用します。強化・一時停止・視点距離も画面のボタンで操作できます。PC操作ではタッチボタンを表示しません。横向きを推奨しますが、縦画面のメニューも指でスクロールできます。


WASDで移動、マウスでカメラ回転、左クリック連打で3連撃。長押しすると最初の1段のあと溜めに入り、離すと強攻撃。ジャンプで十分な高さに達してから左クリックすると、武器ごとの予備動作を挟んで落下攻撃へ移ります。空中連撃はありません。Shiftで回避、Spaceでジャンプ、ホイールでカメラ距離、Eで装備強化・ステータス確認、Escで一時停止します。回避は初期2回分あり、最後に使ってから初期2.5秒で補充。コインで最大5回まで増やし、補充時間も短縮できます。ジャンプ・回避で攻撃を中断できます。銃・ドローン・パルスは自動発動です。

## 挑戦と成長

撃破条件を満たし、残った敵をすべて倒すと、3秒のカウントダウン後に次の区画へ移動します。カウントダウン中も攻撃・移動でき、演出は止まりません。移動先で装備画面が開き、「戦闘を始める」で再開します。9種の地形を巡り、3区画ごとにボスが出現。先へ進むほど敵の強さと報酬が上がります。手動で周回を確定する操作はなく、倒されるまで進みます。

死亡すると、コインの20%、累積コア、コア強化を残して区画1から再挑戦。銃を含む装備レベルと武器分岐はリセットされます。稼いだコインは使った分も死亡時のコア獲得に加算され、端数も引き継ぎます。

死亡演出が終わるとコア強化が開きます。購入できるコア強化が残っているときだけ再挑戦前に確認が表示され、「戻る」で研究画面へ移れます。広いツリーをドラッグ・ホイールで移動できます。平面に枝分かれする26ノードがあり、前提の研究から次の能力へ進めます。3段目の爆風、ジャンプ着地の衝撃、移動による範囲攻撃など、得意な行動を選べます。回避後の強化射撃、標準ライフルの連鎖電撃、空中連射、余剰回復のシールド化、追従衛星、コイン回収による衝撃などを組み合わせられます。研究に使っても累計コアの自動ボーナスは減りません。

## 武器の選択

剣Lv3で重い一撃の大剣か、細く長い射程の槍へ分岐できます。銃Lv3では、敵を貫くビームか近距離の散弾を選べます。コア強化で双刃と回転斧を解放すると、近接Lv3の候補に加わります。Lv3への強化時に必ず一つを選びます。選択後は分岐画面を表示しません。選択後はその挑戦中には戻せません。

ビームは1.4秒間照射し、当たり続けた敵へ継続ダメージを与えます。槍は突き、重刃は両手の重い斬撃です。

ライフルは肩の横に浮かび、レベルで威力と発射間隔を強化します。近接武器の3段目は長射程・高倍率の斬撃です。

## 挑戦中のビルド

コインで全攻撃に効く基礎攻撃力・HP・防御・移動速度も強化できます。基礎攻撃力は高額で、1レベルにつき初期値の20%が加算されます。全攻撃のコア強化倍率とも掛け合わせます。コア強化はHP倍率・割合軽減などで通常強化を補強します。ドローンは命中で敵を減速させ、Lv3で追跡型（敵へのダメージを15%増加）か爆撃型（周囲に追加ダメージ）を選びます。これらの通常強化と武器・機体分岐は死亡時にリセットされます。

突進機は直線の予告レーン、砲撃機は地面の円に攻撃します。砲撃はジャンプでも回避できます。空中射撃の研究はLvに応じて連射速度2〜4倍（ビームは継続威力も増加）。

溜め・落下攻撃もコインで強化できます。強化画面の「ステータス」で現在値と取得したコア強化の効果を確認できます。開き直すと装備タブに戻ります。Lv3以下の武器には「おすすめ」を表示。3つ以上の分岐候補は左右の矢印で切り替えます。強化画面は閉じるボタン・Eキー・枠外クリックで閉じられます（必須の武器選択中を除く）。

パルスはコインで購入すると自動発動する装備です。命中時25〜65%の確率で敵を短時間停止させ、レベルで威力・間隔・停止性能を強化します。死亡時には装備を失い、次の挑戦で購入し直します。

双刃は短射程の速い連撃。回転斧は地上で左クリックを長押しすると回り続け、離す・ジャンプ・回避で中断できます。槍は通常7m・3段目11mの射程で遠くの敵へ追従します。研究で二段ジャンプも解放できます。溜め中のジャンプは攻撃をキャンセルし、空中攻撃にはクリックを離してから押し直す必要があります。落下攻撃はコイン強化で倍率が上昇します。

ボスのHPは画面上部中央の赤いゲージに表示します。シールドはHPの下に並び、購入前のパルスは戦闘HUDに表示しません。溜め中は刀身の発光が青緑から金色に変わり、粒子が増えます。

## 保存

タイトルの「はじめから」は確認後にコイン・コア・研究・記録を初期化します。「つづきから」で保存済みの進行を再開できます。進行はブラウザに保存します。サイトデータを消すと保存も消えます。旧セーブの進行と研究は引き継ぎます。旧版で所持していたライフルは進行中の挑戦ではLv1として残り、次の死亡時にリセットされます。
